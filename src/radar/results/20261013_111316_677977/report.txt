LIMITATIONS
- Labels are provisional XY geometric associations.
- Candidate rows can repeat the same physical object.
- These metrics are classification metrics, not physical detection recall.
- Unlabeled candidates were preserved but excluded from supervised training.
- A predicted class does not confirm that a candidate is a real object.
- Class scores are not calibrated object-existence confidence.
- Balanced sampling can omit majority examples from individual trees.
- Reserved mini scenes were inspected in the earlier LIVE project.
- This is an internal MVP evaluation, not a new external validation.
- Feature importance is impurity-based and is not causal evidence.
